# ToutouCool
Un toutou qui utilise des dispostifs haptiques pour changer son comportement. 

## Différents inputs
| Input                            | Description                                                                                                     | Outputs associés                                                                 |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **Rythme cardiaque de l’humain** | Intégrer un capteur qui détecte le rythme cardiaque de l’utilisateur.                                           | Vibration, respiration, rythme cardiaque du toutou, haut-parleur                 |
| **Pression sur le jouet**        | Intégrer un capteur qui détecte lorsqu’une pression basse, moyenne ou élevée est appliquée sur le toutou.       | Vibration, respiration, rythme cardiaque du toutou, haut-parleur, *fait le mort* |
| **Capteur de mouvement 3D**      | Intégrer un capteur qui permet au toutou de détecter les manipulations en 3D (secousse, rotation sur lui-même). | Mouvement d’étourdissement                                                       |
| **Chaleur**                      | Capteur de chaleur pour éviter de dépasser une température critique.                                            | Chaleur                                                                          |


## Différents outputs
| Output                         | Description                                                             |
| ------------------------------ | ----------------------------------------------------------------------- |
| **Vibration**                  | Le toutou vibre pour relaxer l’utilisateur.                             |
| **Respiration**                | Respiration du toutou qui varie en fonction de l’utilisateur.           |
| **Rythme cardiaque**           | Agit de la même façon que la respiration pour aider à trouver le pouls. |
| **Chaleur**                    | Chauffe en fonction des « émotions » de l’utilisateur.                  |
| **Mouvement d’étourdissement** | Réagit à une stimulation de type secousse / vertige.                    |
| **Devient fou**                | Bouge dans tous les sens → *pattern à définir*.                         |
| **Fait le mort**               | Tombe sur le dos et émet un bruit de mort → *pattern à définir*.        |
